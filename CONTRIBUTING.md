# Contributing to PHPAML Framework

Thank you for helping PHPAML applications stay structured, readable, and safe.

Search existing issues first. Use a private GitHub Security Advisory for vulnerabilities. Never include credentials, private URLs, personal data, or unredacted environment files.

For a focused change: create a descriptive branch, add or update tests and documentation, run `composer test`, and open a pull request explaining the problem, solution, and verification. Discuss large features or architectural changes in an issue before implementation. Avoid unrelated formatting and refactoring.

English is the primary public language; keep French documentation aligned when shared concepts change. Contributions are licensed under the [MIT License](LICENSE), and existing copyright notices must be preserved.

## Français

Les rapports, corrections et pull requests ciblées sont bienvenus. Lancez `composer test`, documentez le résultat et n’incluez aucun secret. Discutez les changements importants dans une issue. Toute contribution est distribuée sous licence MIT.
